# VAIBHAV — THE 22ND EDITION

A birthday-first immersive microsite with romantic touches:
- Dramatic black / cherry red / burgundy / chrome editorial look
- Animated opening screen and oversized birthday typography
- Interactive birthday cake candles
- Couple-photo gallery
- Solo magazine-cover feature for Vaibhav
- Playful tap-to-reveal cards
- Personal love letter and secret birthday message
- Optional user-controlled music

## Preview
Extract the ZIP and open `index.html` in a modern browser.

## Add photos
Put your own images in `photos/` using these exact names:
- `vaibhav-cover.jpg` — best solo portrait for opening hero
- `vaibhav-solo.jpg` — another solo picture for magazine-cover section
- `couple-1.jpg` through `couple-5.jpg` — photos of you two

Use JPG, or update the corresponding filename in index.html if using PNG/WebP. Use images you are comfortable sharing with anyone who has the public site URL.

## Add optional music
Add an audio file you have permission to use as `music/our-song.mp3`. Music starts only after he clicks Play (browser autoplay restrictions).

## Personalise
Open index.html in VS Code or another text editor. Edit the letter, teasing cards, and copy so it sounds like you. The date in the hero currently says "21 November edition"; update it if needed.

## Publish with GitHub Pages
1. Create a GitHub repository called `vaibhav-birthday` and set it to Public.
2. Upload `index.html`, `README.md`, and both folders (`photos`, `music`) with their contents.
3. Commit to the `main` branch.
4. Go to Settings -> Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Select branch `main` and folder `/(root)`, then Save.
7. Wait for the published URL, usually `https://YOUR-USERNAME.github.io/vaibhav-birthday/`.
8. Test the link on phone and laptop before sharing.

A public GitHub Pages website is viewable by anyone with its URL. Do not upload private images or sensitive details you would not want shared.
